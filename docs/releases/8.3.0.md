# Melange 8.3.0

- Tarjetas de crédito independientes de las cuentas con dinero propio. Cada tarjeta tiene nombre, límite, día de corte y día de pago; se puede crear sin una cuenta de débito del mismo banco.
- Compras y gastos fijos cargados a crédito: el gasto se reconoce al registrarlo y reduce el crédito disponible, mientras que el dinero libre cambia al pagar la tarjeta. Se puede ajustar el vencimiento de cada compra según el estado de cuenta.
- MSI vinculados manualmente a una tarjeta. El saldo pendiente completo ocupa crédito y la cuota del mes se incorpora al pago agrupado de esa tarjeta, junto con las compras correspondientes.
- Pagos agrupados desde una cuenta libre, con desglose, abonos parciales, deshacer y validaciones para evitar importes duplicados, sobrepagos y salidas desde vales.
- Cuentas, Movimientos, Deudas, Calendario, proyección, recordatorios y reconstrucción histórica muestran las tarjetas y sus vencimientos.
- Migración automática del libro v8 a v9. Se conservan saldos, movimientos, presupuestos, deshacer y borradores; antes de reemplazar el libro se guarda una copia local del estado anterior. Los respaldos v9 requieren esta versión o una posterior.

El cálculo de vencimientos es orientativo y permite indicar la fecha real de cada cargo. No se calculan intereses, comisiones ni pagos mínimos. Comprueba el desglose y la aplicación de abonos contra el estado de cuenta de tu banco.

Se conserva `app.projectosp` y la firma original para actualizar desde 8.2.0 sin perder datos. Android solicita la confirmación de instalación.
