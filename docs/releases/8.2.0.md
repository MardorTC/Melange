# Melange 8.2.0

- Cuentas con tarjetas rediseñadas: icono por tipo, saldo total destacado, reservas, cajitas y disponible, más acciones de editar y archivar.
- Transferencias hacia vales para distribuir un saldo ya registrado, sin contarlo como ingreso ni gasto. Los vales no pueden transferir dinero hacia afuera, prestar ni pagar deudas.
- Alta de cuentas simplificada: nombre y tipo bastan. Las categorías de los vales quedan en opciones avanzadas, con despensa como predeterminada y detección de una categoría compatible.
- Metas de ahorro renovadas con progreso, importe restante y botón de reservar o liberar.
- Inicio muestra **Tu balance del mes**: ingresos recibidos, salidas registradas, diferencia y compromisos pendientes, con el margen que queda tras cubrirlos.
- Historial de liquidez interactivo: toca un punto o desliza el selector para ver fecha, saldo y variación respecto al registro anterior, con mínimo y máximo del rango.
- Entorno de desarrollo unificado con `npm run setup`, `npm run doctor` y detección automática de JDK, SDK y navegador desde `.tools/`, sin variables manuales. Nueva guía en `docs/entorno.md`.
- Icono de dunas servido con el tipo MIME correcto (`image/svg+xml`).

No hay cambios en el dominio ni en el formato de datos. Se conserva el paquete y la firma original, por lo que la instalación sobre Melange 8.1.0 conserva los datos y solo requiere la confirmación de Android.

Android 8 o posterior con WebView actualizado.
